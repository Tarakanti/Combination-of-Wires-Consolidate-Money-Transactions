Daily Transaction Consolidation Automation

This project implements an automated fintech workflow that simulates daily financial transactions, consolidates customer-wise expenses, generates summary reports, and emails them automatically.
It demonstrates real-world data processing, reporting, and task scheduling used in financial operations. 


Key Features


-Generates 5,000 synthetic financial transactions per day across 200–300 customers. 

-Consolidates transactions customer-wise to reduce transfer costs. 

-Produces daily CSV summary reports automatically. 

-Sends reports via automated email using SMTP. 

-Runs on schedule using Windows Task Scheduler without manual input. 

Tech Stack


-Python, Pandas

-CSV-based data processing

-SMTP email automation

-Windows Batch scripting & Task Scheduler

Project Impact

The system reduces transaction fees, manual effort, and reconciliation errors by combining multiple expenses into a single daily summary, improving operational efficiency in financial workflows.
